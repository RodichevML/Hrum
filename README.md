# Хрум
## Проект по цифровому производству

___Здесь описано что находится в загруженных файлах___

### Main
Основной скетч, который загружен в esp32 s3. В файле audio.h происходит вывод звука с помощью ШИМ. В файле Main.ino происходит обработка акселерометра, и при превышении определённого уровня ускорения запускается вывод звука. Так же есть попытка реализовать работу сервопривода вместе с выводом записанной фразы, но она не доведена до рабочего результата.


### Py-codes
Здесь находятся коды для создания звукого файла из .wav; в файле gain.py версия кода, которая позволяет повысить громкость записанного файла (переменная Gain). Это необходимо из-за специфики обработки и вывода аудио файла. При слишком большом увеличении громкости (>7) могут возникать сильные шумы.

Для создания моноконального файла формата .wav с нужной частотой дискретизации можно использовать утилиту ffmpeg и команду:

ffmpeg -i input.wav -ac 1 -ar 8000 -acodec pcm_u8 output_8k_u8.wav
